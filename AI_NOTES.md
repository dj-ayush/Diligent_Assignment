# 🤖 AI Notes

## Overview

AI was used as a development assistant during this assignment to help with planning, implementation, code review, and documentation. The final project was reviewed, tested, and updated manually before submission.

---

## AI Tools Used

### ChatGPT

Used for:

- Understanding the assignment requirements.
- Planning the project structure.
- Reviewing API design and endpoint organization.
- Improving the project documentation.
- Reviewing the final implementation and suggesting improvements.

### DeepSeek

Used for:

- Generating the initial Django project structure.
- Assisting with Django REST Framework implementation.
- Suggesting serializers, views, and unit test structure.
- Recommending a simple landing page template.

The landing page template was added based on this suggestion. Although it was not part of my original plan, I felt it made the project a little more user-friendly without changing the required functionality.

---

## Other AI Tools Considered

For this assignment, I mainly used **ChatGPT** and **DeepSeek**.

I also considered using tools like **Cursor** and **Claude**, but since this was a relatively small backend project, I found ChatGPT and DeepSeek sufficient for planning, implementation, and reviewing the project.

---

## Manual Review & Improvements

The generated code was not used without review. I went through the implementation and made changes wherever needed.

Some of the work I did included:

- Reviewing the API flow and business logic.
- Improving validation and error handling.
- Simplifying parts of the generated code.
- Organizing the project structure.
- Testing every endpoint using Postman.
- Running the Django test suite.
- Updating the documentation for easier setup and evaluation.

---

## Suggestions Not Implemented

Some AI suggestions were intentionally not included because they were outside the assignment requirements.

These included:

- User authentication
- Pagination
- PostgreSQL instead of SQLite
- Update (PUT/PATCH) endpoints
- Additional analytics and reporting features

I decided to keep the project focused on the required features instead of adding unnecessary complexity.

---

## ✅ Testing & Validation

Before submission, I verified the project by:

- Running the application locally.
- Testing all API endpoints using the included Postman collection.
- Running the Django test suite.
- Checking validation and error responses.
- Reviewing the setup process on a clean environment.
- Ensuring the repository matched the required submission structure.

---

## Final Note

AI helped me speed up development and review different approaches, but I made sure to understand the code before using it. I tested the project, made changes where needed, and verified that it met all the assignment requirements before submitting it.
